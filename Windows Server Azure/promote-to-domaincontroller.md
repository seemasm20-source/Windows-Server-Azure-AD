
# 🖥️  Promote to Domain Controller

  ## Steps

1. Server Manager → Add Roles and Features
 
2. Select Active Directory Domain Services → install

3. Post-deployment: Promote this server to a DC

4. Add new forest → root domain: seemaenterprise.co.in

5. NET BIOS NAME : SEEMAENTERPRISE
 
6. Set DSRM password

7. Review and install → server reboots
 
8. Login with LAB\Administrator → verify ADUC in Tools

9. GO to Local Servers → Check the domain name created → seemaenterprise.co.in ✅
