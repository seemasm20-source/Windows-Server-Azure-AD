
🖥️ Enable and Disable User Accounts

 
 
1. Disable: ADUC → right-click user → Disable Account → icon shows ↓ arrow  → got error message while loggerd in

2. Enable: ADUC → right-click user → Enable Account → icon returns normal  → no error message ✅

3. Test: login as disabled user → "Your account has been disabled" ✅
