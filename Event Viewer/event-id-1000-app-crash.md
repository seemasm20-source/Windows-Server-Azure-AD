
## Event ID 1000 - Application Crash

Log: Application | Event ID: 1000

Faulting application: outlook.exe

Faulting module:      mso.dll

Exception code:       0xc0000005

__Use cases:__

**Ticket:** User: Outlook keeps crashing

**Action:**  Event Viewer → Application → filter 1000 → find faulting module → repair Office installation
