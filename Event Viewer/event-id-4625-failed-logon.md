
## Event ID 4624 - Successful Logon



1. Go to the Windows 11 client machine.

2. Press Windows + L to lock the screen.

3. Sign back in using a wrong password first. (Event ID 4625 recorded has audit failure)

4. Sign back in using Sam's correct password later.
   
	• Result : Event ID 4624 is recorded in the client's Security log with Logon Type 2 . This indicates an Audit Success (the legitimate user successfully unlocked
   their desktop screen)
