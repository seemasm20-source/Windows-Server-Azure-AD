# Windows-Server-Azure-AD


## 👩‍💻 About This Portfolio

This portfolio documents hands-on labs built on
Microsoft Azure using Windows Server 2022 and
Windows 11. It covers real IT Help Desk Tier 1
and Tier 2 tasks including Active Directory
administration, file server management, Group
Policy, Event Viewer analysis, VPN configuration
and remote support tools.

All labs were built and tested on real Azure VMs
with screenshots documenting every step.

## 📋 Skills Demonstrated

### Active Directory
- Create and manage user accounts and OUs
- Reset passwords and unlock accounts
- Create and manage security groups
- Enable and disable user accounts
- Search and move users between OUs

### File Server and Permissions
- Configure NTFS and share permissions
- Understand most restrictive permission rule
- Map network drives manually and via GPO
- Troubleshoot Access Denied errors

### Group Policy
- Create and link GPOs to OUs
- Configure password and lockout policies
- Deploy drive mappings via GPO
- Block USB storage devices
- Troubleshoot GPO not applying

### Event Viewer
- Identify failed logons (Event ID 4625)
- Trace account lockout source (Event ID 4740)
- Diagnose application crashes (Event ID 1000)
- Investigate unexpected shutdowns (Event ID 41)

### Remote Support Tools
- Remote Desktop Protocol (RDP)
- Windows Remote Assistance
- Remote Computer Management
- Quick Assist
